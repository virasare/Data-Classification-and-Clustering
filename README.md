# Orange Data Mining - First Project 🎉

Hey there! 👋  
This is my very first try using [Orange Data Mining](https://orangedatamining.com/).  
The `.ows` file here is part of a class assignment/project where we explored basic data analysis using Orange.

### What's inside?
Just a basic workflow with some standard widgets like File, Select Columns, k-Means, and Scatter Plot.  
Nothing too fancy – still learning! 😄

### How to open
1. Download the `.ows` file.
2. Open [Orange](https://orangedatamining.com/download/).
3. Go to `File > Open Workflow`, and choose this file.

Feel free to explore or reuse.
